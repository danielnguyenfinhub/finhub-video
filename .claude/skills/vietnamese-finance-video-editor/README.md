# vietnamese-finance-video-editor

Turns Daniel's Vietnamese mortgage talking-head recordings into finished FinHub
Reels, each with its own design, on a locked core (brand, compliance, cuts, pacing).

- `SKILL.md` — workflow, iron rules, content → direction decision tree
- `references/` — design architecture + bootstrap, design space, toolkit, edit.json,
  editing principles, landmines
- `scripts/main.py` — design log: `log`, `check`, `add`, `selftest`
- `templates/` — report and error formats; `examples/` — a worked request and report

Repo: `danielnguyenfinhub/finhub-video` (this repository). Composition `MortgageReel`.
