# Background music

Tracks for `edit.json`'s `music` field, e.g. `"music": { "file": "music/calm-morning-keys.mp3" }`.
The mp3s are git-ignored (Pixabay's licence bars redistributing tracks on their own), so on a
fresh checkout download each one from its link and save it here under the name shown.

All tracks are from Pixabay under the [Pixabay Content License](https://pixabay.com/service/license-summary/)
(free for commercial use, no attribution needed). **None is Content ID registered** — checked on
2026-09-25, so Facebook/YouTube shouldn't raise copyright claims. Re-check the track page before
adding a new one: most Pixabay music *is* registered. "AI" means Pixabay labels the track AI generated.
